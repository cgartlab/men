# si-knowledge（知识库管理）

适用场景：知识整理、PKM 检索、项目经验沉淀。M2 阶段以规划为主，接入 Affine / Blinko 后转为日常维护。

## 数据源

| 来源 | 类型 | 地址/说明 |
|------|------|-----------|
| Affine | 协作白板/文档 | 内网 192.168.31.x |
| Blinko | 阅读/摘录管理 | 内网 192.168.31.x |
| knowledge/ | 项目知识沉淀 | 本地目录，写入可复用结论 |

## 知识沉淀规范

1. **可复用才写入** — 一次性信息不入 knowledge/
2. **归纳优先** — 提炼结论，保留原文来源
3. **标注来源** — 每条结论附来源（URL / 文件名 / 摘录 ID）
4. **定期归档** — 过期结论标记 `[archived]`，不删除

## 目录结构（建议）

```
knowledge/
├── topics/       # 按主题归类
├── references/   # 参考链接/摘录
└── decisions/    # 架构/流程决策记录
```
