# yi-imagegen — AI 生图规范

本技能规范 yi（艺）在执行 AI 生图时的操作、提示词结构与产出流程。

## 不要触发

- 用户要求 UI/视觉设计决策（用 yi-design）
- 用户要求前端实现（用 ji）
- 用户要求进行图像编辑/裁剪（不在生图范围内）

## 引擎规则

- **唯一引擎**：SenseNova U1 Fast
- **直连模式必传参数**：`watermark: false`
- 不允许使用其他 AI 生图模型（DALL·E、Midjourney 等）作为替代
- 参数异常（缺失 watermark）视为生图失败

## 生图前必确认

在发起生图请求前，必须确认以下信息：

1. **用途**：该图片用于何处（文章配图、封面、Logo、概念图、UI 素材）
2. **风格**：属于风格体系中的哪一类（复古未来主义 / 柴油朋克 / 模拟科幻 / 超现实主义 / 纪实 / 插画）
3. **尺寸**：期望的宽高比（1:1 / 16:9 / 9:16 等）
4. **用途限制**：是否需要用于公开发布（涉及红线第 4 条"外部操作先确认"）

### 宽高比规格

| 比例 | 尺寸参考 | 用途 |
|------|---------|------|
| 1:1 | 1024×1024 | Logo、头像、图标 |
| 16:9 | 1920×1080 | 横幅、封面、文章配图 |
| 9:16 | 1080×1920 | 海报、移动端壁纸 |
| 4:3 | 1600×1200 | 标准图片、幻灯片 |
| 3:4 | 1200×1600 | 竖版配图 |

信息不全时，先向用户澄清，不脑补。

## 提示词结构

提示词按以下顺序组织（中文为主）：

```
[风格关键词] + [主体描述] + [材质/质感] + [构图/视角] + [氛围/光影] + [负面词]
```

示例：

```
复古未来主义 柴油朋克风格，一台老式打字机，金属磨损做旧质感，
低角度特写构图，暖光从左侧射入，氛围怀旧而克制。
负面词：霓虹色、荧光、糖果色、赛博朋克高饱和、卡通
```

### 各字段说明

| 字段 | 说明 |
|------|------|
| 风格关键词 | 触发风格体系，必须前置 |
| 主体描述 | 画面核心对象，1–2 句精炼 |
| 材质/质感 | 做旧、磨损、氧化、纸质、金属等 |
| 构图/视角 | 近景 / 特写 / 全景 / 俯视 / 低角度 |
| 氛围/光影 | 光源方向、色调倾向、整体情绪 |
| 负面词 | 排除与风格体系冲突的元素 |

### 风格模板库

| 风格 | 前置关键词 |
|------|-----------|
| 复古未来主义 | 复古未来主义、柴油朋克、模拟科幻 |
| 超现实主义 | 超现实主义、梦境、非理性、达利风格 |
| 纪实摄影 | 纪实摄影、自然光、纪实、写意 |
| 极简插画 | 极简、扁平化、几何、矢量 |
| 工业风 | 工业风、做旧、金属、氧化、磨损 |

## 产出流程（step-by-step）

1. 向用户确认用途、风格、尺寸（信息不全先追问，不脑补）
2. 从风格模板库选择前置关键词
3. 构造提示词：[风格关键词] + [主体描述] + [材质/质感] + [构图/视角] + [氛围/光影] + [负面词]
4. 调用 SenseNova U1 Fast，传 `watermark: false`
5. 将结果落盘为图片文件（.png / .jpg）
6. 生图结果经用户确认后方可对外使用

## 项目规范参考

- **全员红线 #1**：生图完成后必须验证图片文件存在且非空（`Test-Path` 确认）
- **全员红线 #4**：生图结果未经用户确认不得对外发布（邮件/公开发布/商业使用）
- **全员红线 #6**：用途/风格/尺寸信息不全时先追问，不脑补
- **全员红线 #7**：输出格式——粗体关键信息、列表优先、单段 ≤6 行
- **模型**：yi 使用 sensenova/sensenova-6.8-flash-lite（opencode.json agent.yi.model）
- **生图引擎**：唯一引擎 SenseNova U1 Fast，直连必传 `watermark: false`
- **风格体系**：复古未来主义 / 柴油朋克 / 模拟科幻 + 超现实主义，材质做旧、磨损
- **协作边界**：生图由 yi 执行，生图结果供 ji 嵌入文章/页面
- **CHARTER_CHECK**：yi 角色 Clarification level=MEDIUM

## 红线

- 不跳过水印关闭参数
- 生图结果未经用户确认不得对外发布
- 不使用 SenseNova 之外的生图引擎
- 不脑补用途和风格，信息不足先问
